# AI detection case studies

AI detector readouts and reproducible linguistic analyses, with explicit limits on what they establish about authorship.

## Dan Sociu and Gemini

The first case examines *La sud de Londra (fragment)*, credited to **Dan Sociu & Gemini** in *Steaua* 10/2026. Pangram 4.1's web interface displayed **Mixed: 66% AI and 34% human**. The analysis preserves all 24 segment observations, describes a spelling discontinuity in the Kraftwerk episode, and measures sentence rhythm and lexical diversity.

**[Read the full report with highlighted passages](https://morarfs.github.io/AIdetection/)**

[Read the report on GitHub](reports/sociu-steaua-2026-11-03/README.md) · [Inspect the data and scripts](reports/sociu-steaua-2026-11-03/)

Detector labels and single-text style patterns do not establish a particular generator, actual edit history, or the truth of an authorship account. The report keeps the detector output separate from the linguistic interpretation.
